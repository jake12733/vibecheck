ABOUT VIBECHECK

바이브코딩 시대, 빠르게 만든 프로젝트를
안전하게 배포하도록 돕는 무료 정적 진단기

VIBECHECK은 Cursor, Claude Code, Bolt, Lovable 등 AI 코딩 도구로 빠르게 제작된 GitHub 프로젝트의 개발 리듬을 재미있게 분석하고, 배포 전 반드시 잡아야 할 실제 보안 구멍(API 키 노출·.env 커밋·XSS·SEO 누락)을 0원 비용으로 찾아주는 클라이언트 사이드 정적 분석 서비스입니다.

1. 왜 VIBECHECK을 만들었나요? (Why VIBECHECK?)

AI 코딩 도구의 발전으로 비개발자나 1인 창업가도 하루 만에 완성도 높은 웹 서비스를 배포할 수 있게 되었습니다. 하지만 빠른 생성 속도의 이면에는 OpenAI·AWS·Firebase 비밀키가 GitHub 공개 저장소에 그대로 커밋되거나, .env 파일이 노출되고, innerHTML XSS 취약점과 SEO 기본 태그가 누락된 채 출시되는 사고가 급증하고 있습니다.

VIBECHECK은 두 가지 축을 명확히 분리해 진단합니다.

  • 전략 A · 바이브코딩 순도 지수 (Fun Heuristic): 커밋당 대량 생성 라인 수, .cursorrules·CLAUDE.md·Co-Authored-By 흔적, AI 주석 패턴 및 현대적 스택 조합을 종합해 공유 가능한 1200×630 결과 카드로 시각화합니다. 이 지표는 재미와 참고를 위한 휴리스틱입니다.
  • 전략 B · 보안·품질 건강검진 (100% Objective Facts): 실제 소스 파일의 정규식·정적 패턴을 검사해 평문 API 키 노출, .env·개인키 파일 커밋, XSS 싱크, eval(), SEO 메타태그 누락 등 객관적 팩트와 정확한 파일·줄 번호만 보고합니다.

2. 100% 브라우저 실행 · Zero-Server 프라이버시 원칙

귀하의 소스 코드와 토큰은 어떤 외부 서버에도 저장되지 않습니다.

VIBECHECK은 백엔드 DB가 없는 순수 정적 웹 애플리케이션입니다. 공개 GitHub REST API와 Raw 파일 조회, 코드 붙여넣기 분석 모두 사용자의 웹 브라우저 안에서 직접 실행됩니다.

3. 운영 · 보안 리팩토링 문의 (Contact)

진단에서 발견된 치명적 키 노출 복구, Supabase/Firebase 보안 규칙(RLS) 잠금, XSS 제거, SEO 및 Core Web Vitals 성능 개선 작업이 필요하신 경우 메인 페이지의 [보안 · 코드 리팩토링 의뢰하기]를 통해 리포트를 바로 전달하실 수 있습니다.
