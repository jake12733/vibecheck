GIT HYGIENE · 저장소 정리

Git에 node_modules·빌드 폴더를 실수로 커밋했을 때
1분 만에 깔끔하게 정리하는 법

.gitignore 없이 git add .을 실행하면 수만 개의 패키지 파일이 GitHub에 올라가 클론 속도가 느려지고 Vercel/Cloudflare 배포가 실패하거나 저장소 용량 경고가 발생합니다.

UPDATED 2026-11-25READ TIME: 2 MINGIT REMOVE NODE_MODULES

1단계: 표준 Node/Next/Vite .gitignore 생성

프로젝트 최상단 루트에 .gitignore 파일을 만들고 아래 항목을 저장합니다.

node_modules/
.next/
dist/
build/
.vercel/
.env
.env*.local
.DS_Store
*.log

2단계: 로컬 파일은 살려두고 Git 추적만 안전하게 해제

--cached 옵션을 쓰면 내 컴퓨터의 node_modules는 그대로 남고 Git 인덱스에서만 깔끔하게 제거됩니다.

git rm -r --cached node_modules
git add .gitignore
git commit -m "chore: untrack node_modules and add .gitignore"
git push

3단계: 이미 커밋된 저장소 용량까지 완전히 줄이고 싶다면

과거 커밋에 수백 MB가 남아 클론이 느린 경우 git-filter-repo --invert-paths --path node_modules/로 히스토리를 압축하면 저장소 크기가 1/50 수준으로 줄어듭니다.

내 저장소에 .gitignore 누락·불필요한 파일이 있는지 확인

VIBECHECK이 파일 트리 전체를 스캔해 위생 점수를 바로 계산해 드립니다.
