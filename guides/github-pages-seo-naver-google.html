SEO & MONETIZATION · 검색 등록

GitHub Pages 무료 사이트 구글·네이버 검색 등록 및
구글 애드센스 승인 실전 체크리스트

GitHub Pages는 서버 호스팅 비용 0원으로 전 세계 CDN을 쓸 수 있지만, 기본 설정만으로는 검색 노출과 애드센스 승인이 자동으로 열리지 않습니다. 반드시 갖춰야 할 기술 SEO 파일과 콘텐츠 요건을 정리했습니다.

UPDATED 2026-11-25READ TIME: 5 MINGOOGLE SEARCH CONSOLE · NAVER SEARCH ADVISOR

1. 커스텀 도메인 연결 (애드센스 필수 관문)

username.github.io 서브도메인에서는 구글 애드센스 심사 신청이 제한됩니다. .com, .kr, .dev 같은 최상위 도메인을 구매한 뒤 DNS에 GitHub Pages A 레코드 4개(185.199.108~111.153)와 루트 CNAME 파일을 연결하고 Enforce HTTPS를 켜세요.

2. robots.txt와 sitemap.xml 필수 배치

네이버 검색로봇(Yeti)과 구글봇(Googlebot)이 모든 페이지를 빠짐없이 색인하도록 사이트 루트에 두 파일을 둡니다.

# robots.txt
User-agent: *
Allow: /
User-agent: Yeti
Allow: /
Sitemap: https://yourdomain.com/sitemap.xml

3. 구글 서치콘솔 & 네이버 서치어드바이저 등록 순서

  1. Google Search Console: 도메인 또는 URL 접두어 등록 → HTML 메타태그 인증 → 좌측 [Sitemaps]에 sitemap.xml 제출 → 주요 페이지 색인 생성 요청.
  2. 네이버 서치어드바이저: 웹마스터 도구 사이트 추가 → naver-site-verification 메타태그 인증 → [요청 → 사이트맵 제출] 및 [웹 페이지 수집 요청].

4. 구글 애드센스 "가치 없는 콘텐츠" 거절을 피하는 4가지 요건

  • 필수 신뢰 페이지 3종: 개인정보처리방침(구글 광고 쿠키 고지 포함), 이용약관, 서비스 소개 페이지가 헤더/푸터에서 명확히 연결되어야 합니다.
  • 충분한 독자적 텍스트 콘텐츠: 도구 1페이지만 두지 말고, 검색 유입을 일으키는 고품질 가이드 글(최소 10편 이상, 각 1,000자 이상)을 함께 배치하세요.
  • 깨진 링크 0개 & 모바일 반응형: 모든 내부 링크가 HTTP 200으로 열리고, 모바일 화면에서 글자 잘림이나 가로 스크롤이 없어야 합니다.
  • 선(先) 트래픽 확보: 검색엔진 색인이 끝날 때까지 X·Reddit·GeekNews·커뮤니티에 결과 공유 기능으로 초기 자연 방문자를 먼저 유입시키면 색인과 심사 모두 훨씬 빨라집니다.
