개인정보처리방침 (Privacy Policy)

최종 시행일: 2026년 11월 25일 · VIBECHECK은 이용자의 소스 코드와 개인정보를 최우선으로 보호합니다.

1. 수집하는 정보 및 100% 브라우저 로컬 처리

VIBECHECK은 회원가입이나 로그인을 요구하지 않습니다. 사용자가 입력하는 GitHub 공개 저장소 URL, 선택적 GitHub Personal Access Token, 직접 붙여넣은 소스 코드는 사용자의 웹 브라우저 메모리 내에서만 처리되며 VIBECHECK 운영 서버로 전송되거나 저장되지 않습니다.

  • 로컬 스토리지(localStorage): 언어 설정(vc_lang)과 최근 진단 기록(vc_hist)은 사용자 편의성을 위해 사용자 기기의 브라우저 내부에만 저장됩니다. 브라우저 데이터 삭제를 통해 언제든 즉시 지울 수 있습니다.
  • 보안 수정 의뢰 폼: 사용자가 자발적으로 [보안 · 코드 리팩토링 의뢰하기] 폼을 작성해 제출하는 경우에 한해, 견적 회신 목적으로 입력한 연락처(이메일 또는 메신저 ID)와 대상 저장소 정보를 처리합니다.

2. 제3자 API 통신

GitHub 저장소 진단 기능 사용 시, 사용자의 브라우저는 GitHub 공식 공개 API(api.github.com 및 raw.githubusercontent.com)와 직접 통신합니다. 이 과정은 GitHub의 개인정보처리방침 및 API 이용약관의 적용을 받습니다.

3. 쿠키(Cookie) 및 Google AdSense 광고 게재 안내

본 사이트는 무료 서비스 유지를 위해 Google AdSense 등 제3자 광고 네트워크를 사용할 수 있습니다.

  • Google을 포함한 제3자 공급업체는 쿠키를 사용하여 사용자의 이전 본 웹사이트 또는 다른 웹사이트 방문 기록을 기반으로 광고를 게재할 수 있습니다.
  • Google의 광고 쿠키 사용으로 Google 및 파트너는 사용자의 본 사이트 및 인터넷상의 다른 사이트 방문 기록을 바탕으로 맞춤형 광고를 제공할 수 있습니다.
  • 사용자는 Google 광고 설정(adssettings.google.com)에서 언제든 맞춤형 광고를 거부(Opt-out)할 수 있으며, www.aboutads.info를 통해 제3자 공급업체의 맞춤형 광고 쿠키 사용을 비활성화할 수 있습니다.

4. English Summary (For Global Visitors)

VIBECHECK runs static GitHub & source code analysis 100% client-side inside your browser. We do not store your pasted code or optional GitHub tokens on any backend server. Scan history is saved strictly in your browser's localStorage. Third-party ad vendors (such as Google AdSense) may use cookies to serve relevant ads; you may opt out anytime via Google Ads Settings.

5. 개인정보 보호 문의

개인정보 삭제 요청이나 방침 관련 문의는 메인 페이지의 의뢰/문의 창구 또는 사이트에 고지된 운영자 이메일을 통해 요청하시면 지체 없이 조치합니다.
