내 소스 코드나 GitHub 토큰이 외부 서버로 전송·저장되나요?

아니요. VIBECHECK은 백엔드 서버가 없는 100% 브라우저 실행 정적 분석 도구입니다. 입력한 코드와 선택적 토큰은 브라우저 메모리 내에서만 처리되며 외부 서버에 절대 저장되지 않습니다.

바이브코딩 순도(%)가 높게 나오면 나쁜 코드인가요?

전혀 아닙니다. 바이브코딩 지수는 AI 코딩 에이전트 활용 리듬과 스택 조합을 재미있게 보여주는 참고 지표이며, 실제 배포 안전성과 코드 건강도는 우측 [전략 B · 보안·품질 등급(A+~F)]을 기준으로 점검하시면 됩니다.

GitHub Pages 배포 주소(username.github.io/repo)를 넣어도 진단되나요?

네! https://owner.github.io/repo 주소를 그대로 붙여넣으셔도 자동으로 원본 GitHub 저장소(owner/repo)를 찾아 정적 보안·품질 진단을 수행합니다.

비공개(Private) 저장소나 GitHub 무료 API 한도 초과 시엔 어떻게 하나요?

상단의 [코드 / HTML 직접 붙여넣기] 탭을 사용하면 GitHub API 호출 없이 무제한 무료로 즉시 진단할 수 있으며, 개인 GitHub Token을 입력하면 시간당 5,000회까지 연속 스캔이 가능합니다.
